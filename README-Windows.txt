========================================
🌙 Twilight Music - Windows PC Edition
========================================

How to Use on PC / Windows:

Option 1: Direct Desktop Executable (.exe)
------------------------------------------
1. Double-click "Twilight-Music-PC.exe" or "Launch-Twilight-Music.bat".
2. Twilight Music will open instantly in a native, distraction-free desktop window!

Option 2: Install as a Windows Desktop App (PWA)
-----------------------------------------------
1. Open Google Chrome or Microsoft Edge.
2. Go to: http://localhost:3000
3. Look at the address bar on the right side and click the "Install App" icon (or Menu -> Apps -> Install this site as an app).
4. Twilight Music will be installed directly into your Windows Start Menu, Taskbar, and Desktop as a standalone PC app with offline support!
